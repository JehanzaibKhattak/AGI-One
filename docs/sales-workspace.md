# Sales workspace

- **Leads:** Capture company, contact details, source, sales owner, expected value and close date. Qualify a lead, then convert it atomically into a customer, contact and opportunity. An existing customer can be selected in the same branch. Converted leads are locked and retain the generated links; repeat conversion and direct status bypasses are rejected. Customer deduplication is manual: select the existing customer before conversion.
- **Tasks & reminders:** Assign tasks to current workspace members who can view sales and the task's branch. Link customer, opportunity or lead; set priority, due time and an optional reminder. Browser-local input is stored as UTC. A signed-in user sees reminders for their own unfinished tasks at the chosen time or when overdue, checked every 30 seconds while the app is visible. These are persistent in-app reminders, not background push/email notifications. Reassign tasks after a teammate is revoked; historical assignee IDs remain on tasks, while revoked members lose access.
- **Pipelines:** The default configuration retains existing sales stages. Owners can create more pipelines, order/add/rename stages, and set probabilities and open/won/lost outcomes. A won stage must be 100%, lost 0%. Editing a stage updates its deals and the forecast in the same transaction. Occupied stages cannot be removed or change outcome until their deals are moved. Legacy opportunities without pipeline IDs use the default pipeline.
- **Opportunities:** Search and page deals by pipeline/stage; edit fields and move stages. Probability follows stage configuration. A server-generated outcome keeps dashboards and customer counts correct even after closed stages are renamed. Customer/contact/product references and branch permissions are enforced by the existing transaction and record-link system.
- **Forecast:** The database groups deals by owner, stage and outcome within an inclusive expected-close date range. Pipeline, branch and exact owner filters apply. Weighted open pipeline is the sum of value × probability / 100; the combined forecast adds closed-won value. Lost deals contribute zero weighted value. This is a stage-based forecast, not an AI prediction, recognized revenue, quota system, or forecast-submission workflow.
- **Email & calendar:** See [Microsoft 365 setup](microsoft-365.md). The connection is personal and read-only; live activation needs an Entra app registration and server secrets.

The new directories use server pagination; forecasts use SQL aggregation. Legacy screens still load their authorized record projection and the workspace-wide revision still serializes writes. Production capacity, long-running workers, SSO/MFA, privacy review, compliance and pilot acceptance remain separate release gates.
